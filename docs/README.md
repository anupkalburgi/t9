# t9 documentation

## Getting started

- [concepts.md](getting-started/concepts.md): projects, items, decisions, journal entries, sessions, the inbox, the
  brief, the vault. Read this first.
- [humans.md](getting-started/humans.md): install, link a project, connect Claude Code or Codex, daily use,
  editing the vault, troubleshooting.
- [agents.md](getting-started/agents.md): the protocol a coding agent follows: what to read at the start of a
  session, what to record while working, and how to hand off.
- [tui.md](getting-started/tui.md): `t9 tui`, and other ways to view the vault (Obsidian, editors, git history).
- [decisions.md](getting-started/decisions.md): the decision log: recording decisions, rejections and ideas, and
  how they are recalled in later sessions.
- [cli-reference.md](getting-started/cli-reference.md): every command and option.

## Design

- [architecture.md](design/architecture.md): how the system is built: components, storage formats, the index,
  read and write paths, sync, project and session resolution, the brief, concurrency, and planned components.
- [design.md](design/design.md): why t9 is built this way: the problem, goals, and the key decisions with the
  alternatives that were rejected.
- [performance.md](design/performance.md): latency and memory measurements, how to reproduce them, and the
  optimizations that mattered.
